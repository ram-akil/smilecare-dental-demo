# SmileCare Dental Studio — Website Demo

A fictional premium dental clinic website created for client presentation.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap 5.3
- Bootstrap Icons
- Google Fonts

## Run
Open `index.html` directly in a browser, or serve the folder from a local development server.

## Demo-only content
All clinic names, doctors, contact information, testimonials, statistics, addresses and imagery are fictional placeholders. Replace them with client-approved information before deployment.

## Image replacement
The project deliberately uses styled visual placeholders instead of copying photographs from the reference clinic. Replace placeholders with licensed/approved client photography.
